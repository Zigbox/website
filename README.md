# zigbox.org

The source of [zigbox.org](https://zigbox.org): the landing page and the error-code pages of
[Zigbox](https://github.com/Zigbox/zigbox) and [Zigcube](https://github.com/Zigbox/zigcube).
See [AGENTS.md](AGENTS.md) for the layout.

It is deployed to a Cloudflare Worker by `.github/workflows/deploy.yml` (`wrangler.jsonc`).
